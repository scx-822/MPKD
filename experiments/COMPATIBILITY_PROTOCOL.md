# Logit 蒸馏方法兼容性实验

## 实验目的

验证 CRLD-Proto 的原型修正是否不仅适用于标准 KD/CRLD，还能与 DKD、NKD 等类别级 Logit 蒸馏目标兼容。该实验借鉴参考模板的表格组织形式，但不复制 RVKD 的方法定义或数值。

## 固定架构

1. ResNet56 -> ResNet20
2. ResNet110 -> ResNet32
3. ResNet32x4 -> ResNet8x4
4. WRN40-2 -> WRN16-2
5. WRN40-2 -> WRN40-1
6. VGG13 -> VGG8

## 实现约束

- 不能把两个完整总损失直接相加，否则 CE 和 KD 会被重复计算。
- 保留 KD、DKD 或 NKD 的官方类别级蒸馏定义。
- 在同一弱/强视图 CRLD 框架中构造同视图与交叉视图项。
- CRLD-Proto 只修正教师强视图的同视图目标；弱视图目标和两条交叉视图关系不变。
- DKD/NKD 需要实现“以目标概率分布为输入”的逐样本损失，才能先做原型概率融合、再应用置信度掩码；不能把融合概率随意取对数后冒充原始教师 logits。
- 每个组合先做 1 batch 前向/反向和 1 epoch 冒烟测试，通过后再运行 240 epochs。

## 执行时机

先完成 A–E 与门控消融。兼容性适配器实现并通过数值单元测试后，再生成正式运行命令；当前不提供会重复计损失的临时命令。
